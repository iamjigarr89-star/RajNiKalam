GitHub Sync સેટિંગ્સ

અહીં સેટિંગ્સ સેવ કર્યા પછી, Admin Page પર જે પણ Publish / Draft / Save કરશો તે બધું આપોઆપ તમારા GitHub Repository ના data.json ફાઈલમાં commit થઈ જશે — એટલે કે તે કોડમાં કાયમી સેવ થઈ જશે અને દરેક વિઝિટરને દેખાશે.

ટોકન કેવી રીતે બનાવવો: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token → આ repository માટે Contents: Read & Write પરમિશન આપો.
✓ GitHub publishing હવે server-side છે. Token browserમાં રાખવામાં આવતો નથી. Serverના .env માં GITHUB_TOKEN configure કરો.
